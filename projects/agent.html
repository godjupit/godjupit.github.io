项目方向

Agent Runtime 关注模型与外部工具之间的执行过程。它涉及工具的描述与调用、结果返回，以及各个执行步骤的组织；MCP 是这个方向中的一个重点。

关注的问题

  • 工具调用：理解工具参数、执行结果与模型上下文之间的关系。
  • MCP：探索工具和资源接入的接口与交互方式。
  • 执行编排：理解 Agent 的执行步骤、状态与工具结果如何衔接。
